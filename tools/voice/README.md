# 語音工具

用 Gemini 的語音設計（`gemini-3.8-flash-tts`）設計露米婭與老師（魔導書）的聲音，調整後製音效，確定之後批次產生劇情台詞與露米婭頭上泡泡台詞的配音。

只用 Python 標準函式庫（3.8 以上），不需要 pip install。**音效控制台與 MP3 輸出需要 ffmpeg**，建議在 WSL 執行（Windows 沒有 ffmpeg；WSL 用 `sudo apt install ffmpeg` 安裝，內含需要的 rubberband 等濾鏡）。

```bash
python3 tools/voice/gui.py
```

打開 http://127.0.0.1:8766 。API 金鑰放在環境變數 `GEMINI_API_KEY`（可在設定裡改名稱），或在網頁上輸入（只存在記憶體裡）。

## 1. 聲音製作

上方選角色（露米婭／魔導書）。左邊是設計與試講，右邊是音效控制台與比較區。

### 聲音設計

1. **聲音名稱**：這個候選聲音的名稱（雲端上的 display_name，也是清單上顯示的名稱；之後可以改名）。
2. **聲音敘述**：voice design 的 prompt。寫**永久的特質**：年齡、音色、音高、口音（加上 `Speaks natural, native Japanese.`）、語速、平常的語氣。一句一句的情緒不要寫在這裡，寫在試講的「語氣」。
   - **✨ AI 細化**：用 `gemini-3.5-flash-lite` 補上你可能沒想到但會想要的細節（依 Gemini 語音設計的寫法：2～4 句、只寫永久特質）。可以在旁邊寫「想調整的方向」，例如「再成熟一點」。
   - 草稿和方向可以用中文寫；**建議的聲音敘述會寫成配音的語言**（看設定的 `language_code`，例如 `ja-JP` → 日文），改了什麼的說明用中文。
   - 結果先顯示在建議框（附上改了什麼的說明），可以先修改，按「套用到聲音敘述」才會放進去。
3. **自我介紹**：建立聲音後自動用新聲音唸一次並播放（建立時 API 附的試聽是模型自己挑的句子，常常是英文，只聽音色）。
4. 按「**建立聲音**」：在雲端存下一個候選聲音。

### 測試台詞

- 選要用哪個聲音、從劇本選一句（會填入台詞與它的語氣），或自己打。
- **標籤按鈕**：在游標位置插入 `<sigh>`、`<giggle>`、`<short pause>` 這類標籤（滑鼠停在按鈕上有中文說明）。台詞是日文也要用英文標籤。
- **語氣（style）**：這一句的情緒與說法，例如 `cheerful and energetic`、`whispered urgently`，或日文的描述。
- 按「產生」後自動用音效控制台的設定播放。

### 候選聲音與試講紀錄

- 每個候選聲音的所有試講：▶ 用目前的音效播放，**A／B** 放進比較區。
- 「設為正式」：批次產生用這個聲音。「用這個敘述」：把它的聲音敘述放回聲音設計來微調。
- 「移出清單」：只從清單移除，雲端上的聲音保留（之後可以再讀回來；試講紀錄不保留）。「刪除」：雲端上的聲音也會刪掉（每個專案最多 200 個，一年後過期）。

### 雲端上的所有聲音

- 列出這個 API 專案在雲端上的所有聲音（打開時自動讀取）。
- 不在候選清單裡的，可以選一個角色「**讀回**」：名稱、性別、聲音敘述與雲端上的試聽會一起讀回來，變成那個角色的候選聲音。預設會接著用這個聲音唸一次自我介紹（可以取消勾選）。
- 在這裡「刪除」會刪掉雲端上的聲音，在候選清單裡的也會一起移除。

### 音效控制台

試聽、比較區、批次產生都用**同一條處理流程**（ffmpeg），聽到的就是輸出的。處理順序：

| 分類 | 項目 | 說明 |
|---|---|---|
| 剪輯 | 裁掉前後的靜音、前後保留 | 讓每句的節奏一致；裁切處自動淡入淡出 |
| 音高與速度 | 音高（±6 半音）、保留共振峰、語速（0.7～1.4×） | 用 rubberband：語速不影響音高。關掉「保留共振峰」會有變聲器感（升調像小孩） |
| 音色（EQ） | 低切、厚度 200Hz、鼻音／悶 1kHz、清晰度 3.5kHz、空氣感 8kHz、齒音抑制 | |
| 動態 | 壓縮 | 縮小大小聲的差距，聽起來更飽滿穩定 |
| 空間 | 殘響量、殘響長度 | 程式產生的房間殘響（卷積）；一點點像在店裡說話 |
| 音量 | 響度標準化（目標 LUFS）或增益 | 批次建議打開：每句音量一致。最後有防爆音的限制器 |

- 雙擊項目名稱：單獨重設。改過的項目名稱會變色。
- **預設**：內建「原音、基本整理、明亮可愛、溫暖沉穩、小房間」，也可以「另存…」自己的（存在 `fx_presets.json`）。
- 控制台的設定是每個角色各一份草稿（存在瀏覽器）。**「套用到批次」**才會存進 `profiles.json`，批次產生用這個設定；「載入批次設定」把批次的設定拿回控制台。

### 比較區

- A、B 各選一段試聽（或用清單上的 A／B 按鈕），可以各自決定要不要套用音效（例如同一段的原音 vs 套音效）。
- **時間軸同步**：播放中切換 A／B，從同一個秒數接著播。可以循環、每輪自動交替 A／B。
- 波形：A 在上、B 在下，點一下跳到那個位置。
- 調整音效控制台時，套用音效的一方會自動重新處理，播放不中斷。
- 鍵盤：空白鍵 播放／暫停、`1`／`2` 切換 A／B、`X` 互換。

## 2. 批次產生

- 列出所有要配音的台詞：
  - **劇情**：`src/game/config/script.json` 裡露米婭與老師說的話。旁白不配音，只有動作的句子也不配音。
  - **泡泡**：語言檔裡 `mutter.`、`wish.lines.`、`event.lines.`、`lines.` 開頭的陣列，每一句一個檔。
- 文字用設定的**配音語言**（預設日文），所有語言共用這一套配音，字幕跟著遊戲語言。
- **語氣**：預設用劇本的動作描述。可以在表格裡逐句改，存在 `styles.json`。
- **送給模型的台詞**：預設是原始台詞（遊戲的字幕），可以逐句改，例如加上 `<sigh>` 這類標籤（表格上方的標籤列會插入到正在編輯的那一句）。只影響配音，字幕不變；存在 `speech.json`。
  - 清空或改回和原始台詞一樣，就恢復用原始台詞。
  - 改過之後原始台詞又改了（例如修了翻譯），會標示「請確認」，你改過的版本不會被蓋掉。
- **音效**：用各角色「套用到批次」的設定。
- 狀態：
  - **還沒產生**／**要重做**（文字、語氣、聲音改了）：要呼叫 API。
  - **只需重新處理**（只有音效或輸出格式改了）：用 `raw/` 留著的原始音檔在本機重新處理，**不用呼叫 API**。
- 「產生待處理的」兩種都做；「只做本機重新處理的」只做不用 API 的。單句「重做」與「重做勾選的」會重新呼叫 API。

## 檔案

| 檔案 | 內容 | 版本控制 |
|---|---|---|
| `config.json` | API 網址、模型、配音語言、輸出格式 | ✅ |
| `profiles.json` | 聲音敘述、候選聲音、正式使用的 voice_id、批次用的音效（fx） | ✅ |
| `fx_presets.json` | 自己另存的音效預設 | ✅ |
| `styles.json` | 逐句指定的語氣 | ✅ |
| `speech.json` | 逐句改過的「送給模型的台詞」（和改的時候的原始台詞） | ✅ |
| `state.json` | 每句產生時的內容雜湊與音效設定雜湊（判斷要不要重做） | ✅ |
| `fx.py` | 音效的處理流程 | ✅ |
| `samples/` | 試聽、試講的聲音；`samples/.fx/` 是套音效後的暫存 | ❌（.gitignore） |
| `raw/` | 批次產生的原始音檔（套音效之前，只改音效時用來重新處理） | ❌（.gitignore） |
| `public/voice/<台詞 ID>.mp3` | 遊戲用的配音（已套音效） | ✅ |
| `public/voice/manifest.json` | 有配音的台詞清單（遊戲只播清單裡有的） | ✅ |

`raw/` 不進版本控制：換一台電腦時，沒有原始音檔的句子改了音效就要重新呼叫 API。音效功能之前產生的配音沒有套過音效，會直接當成原始音檔使用。

## 台詞 ID

- 劇情：`<場景>.<編號>`，例如 `opening.07`。
- 泡泡：`<語言檔 key>.<第幾句，兩位數>`，例如 `mutter.global.03`。
- 老師的信：`letter.<n>.<to|body|closing>.<第幾段，兩位數>.<第幾小句>`，例如 `letter.1.body.02.3`（第一封信第 2 段的第 3 小句）。
  - 信太長不好給語氣指示，所以工具把配音語言的每一段依句子（。！？）拆成小句，太短的句子和下一句合併（每小句約 20 字以上）。每小句可以各自寫語氣、改送給模型的台詞；表格的「整段」可以看到這一段的全文。
  - 遊戲打開信時照順序播（小句之間停 0.25 秒、段落之間停 0.7 秒），正在唸的段落會淡淡標出來；畫面上的文字跟著遊戲語言，照段落對應。
  - 改了某一段的配音語言文字，那一段的小句可能重新拆分，編號會跟著變：改完請確認那一段的語氣。
  - 由誰配音、有哪幾封：`script.json` 的 `letters`。
- 有了配音之後，**劇情的編號不要改**。要插入新句子就用新的編號（例如 `07b`），播放順序看 `script.json` 的清單。
- **泡泡台詞是照第幾句對應的**：在陣列中間插入或刪掉一句，後面的配音會對錯。要加新句子就加在陣列最後面。
