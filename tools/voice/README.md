# 語音工具

用 Gemini 的語音設計（`gemini-3.8-flash-tts`）設計露米婭與老師（魔導書）的聲音，確定之後批次產生劇情台詞與露米婭頭上泡泡台詞的配音。

只用 Python 標準函式庫（3.8 以上），不需要 pip install。有 ffmpeg 時會把聲音轉成 MP3（檔案小很多）；沒有就存 WAV。

```bash
python3 tools/voice/gui.py
```

打開 http://127.0.0.1:8766 。API 金鑰放在環境變數 `GEMINI_API_KEY`（可在設定裡改名稱），或在網頁上輸入（只存在記憶體裡）。

## 1. 聲音設計

1. 在角色卡片寫聲音描述：年齡、性別、音色、口音、平常說話的語氣（英文描述通常比較準）。建議加上 `Speaks natural, native Japanese.`（或配音語言）。
2. 按「建立並試聽」：在雲端存下一個**候選聲音**，接著**自動用這個聲音唸一次自我介紹**（卡片上可以改）並播放。
   - 建立時 API 附的試聽是模型自己挑的句子，常常是英文，只拿來聽音色；判斷日文效果聽自我介紹。
3. 在候選聲音下面「試講」：從下拉選單選自我介紹或這個角色的任何一句劇情台詞（會自動填入台詞與它的語氣），也可以自己改；語氣（style）例如 `cheerful and energetic`、`whispered urgently`、`驚いたように`。
4. 滿意的按「**設為正式**」。批次產生會用正式聲音。
5. 不要的候選按「刪除」：雲端上的聲音也會刪掉（每個專案最多 200 個，一年後過期）。「雲端上的所有聲音」可以清理不在清單裡的。

## 2. 批次產生

- 列出所有要配音的台詞：
  - **劇情**：`src/game/config/script.json` 裡露米婭與老師說的話。旁白不配音，只有動作的句子也不配音。
  - **泡泡**：語言檔裡 `mutter.`、`wish.lines.`、`event.lines.`、`lines.` 開頭的陣列，每一句一個檔。
- 文字用設定的**配音語言**（預設日文），所有語言共用這一套配音，字幕跟著遊戲語言。
- **語氣**：預設用劇本的動作描述（例如「驚いて尻もちをつく」）。可以在表格裡逐句改，存在 `styles.json`。
- **送給模型的台詞**：預設是原始台詞（也就是遊戲的字幕），可以逐句改，例如加上笑聲、嘆氣這類音效詞（「えへへっ……」「はぁ……」）。只影響配音，字幕不變；存在 `speech.json`。
  - 清空或改回和原始台詞一樣，就恢復用原始台詞。
  - 改過之後原始台詞又改了（例如修了翻譯），會標示「請確認」，你改過的版本不會被蓋掉。
  - 試講的下拉選單也用改過的版本。
- 「產生待處理的」只做還沒產生、或文字／語氣／聲音改過的句子。也可以勾選或單句重做。

## 檔案

| 檔案 | 內容 | 版本控制 |
|---|---|---|
| `config.json` | API 網址、模型、配音語言、輸出格式 | ✅ |
| `profiles.json` | 聲音描述、候選聲音、正式使用的 voice_id | ✅ |
| `styles.json` | 逐句指定的語氣 | ✅ |
| `speech.json` | 逐句改過的「送給模型的台詞」（和改的時候的原始台詞） | ✅ |
| `state.json` | 每句產生時的內容雜湊（判斷要不要重做） | ✅ |
| `samples/` | 試聽、試講的聲音 | ❌（.gitignore） |
| `public/voice/<台詞 ID>.mp3` | 遊戲用的配音 | ✅ |
| `public/voice/manifest.json` | 有配音的台詞清單（遊戲只播清單裡有的） | ✅ |

## 台詞 ID

- 劇情：`<場景>.<編號>`，例如 `opening.07`。
- 泡泡：`<語言檔 key>.<第幾句，兩位數>`，例如 `mutter.global.03`。
- 有了配音之後，**劇情的編號不要改**。要插入新句子就用新的編號（例如 `07b`），播放順序看 `script.json` 的清單。
- **泡泡台詞是照第幾句對應的**：在陣列中間插入或刪掉一句，後面的配音會對錯。要加新句子就加在陣列最後面。

## 注意

- 語音設計的 API 文件沒有寫清楚合成時回傳的欄位，工具會在回應裡找音訊資料（WAV 或原始 PCM 都可以）。如果第一次實際使用時出現「回應裡找不到音訊」，把錯誤訊息給我，我再對照實際的回應調整。
- 沒有 ffmpeg 時存 WAV。之後裝了 ffmpeg，那些 WAV 的句子會自動變成「要重做」，重做就會轉成 MP3。WSL：`sudo apt install ffmpeg`。
